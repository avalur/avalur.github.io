Deep Dive 1: Air ADE & AI Delegation

Benchmarking LLM automation costs and exploring human/AI task delegation boundaries

Air ADE: AIAU-Bench

N. Magomedeminov, S. Suglobov | Mentors: D. Domanskii, I. Dolgov

  • Problem: Over-reliance on expensive LLMs out of fear cheaper models degrade quality.
  • Solution: Developed AIAU-Bench to systematically validate lightweight models on automations.
  • Result: Identified tasks where cheaper models achieve quality parity, cutting costs.

klibs.io: Delegation Boundaries

Daniel Volostnov | Mentors: N. Vlaev, N. Pachkov

  • Goal: Map where AI saves engineering hours vs where manual coding is superior.
  • Vectors: Spec creation, agent skills, AI as critic, and feature delivery.
  • Result: Clear empirical boundaries for effective task delegation in open-source.
Takeaway: Don't guess which LLM or task fits — build targeted benchmarks and clear delegation boundaries before scaling.
[11:30 - 13:30]
AIAU-Bench proved where cheaper LLMs can power Air ADE automations without quality loss. Daniel on klibs.io defined exact boundaries for task delegation.

Insights 1 & 2: Architecture & Context

Why software structure dictates agent capability

#1: Architecture > Prompt Engineering

Clean modular code with explicit interfaces makes an average agent brilliant. In spaghetti code, no prompt prevents hallucinations.

Modular design is the ultimate prompt optimizer.

#2: Context is the #1 Bottleneck

"Context stuffing" degrades reasoning. Agents need surgical retrieval: IDE symbol indices, scoped inspection, and bounded outputs.

Pruned context windows prevent agent looping.

"If your codebase is hard for a junior developer to navigate, it will be twice as hard for an autonomous agent."
[19:00 - 21:00]
Insight 1: Modular architecture beats prompt engineering. Insight 2: Context window bloat degrades agent reasoning; surgical retrieval is key.

Insights 3 & 4: Testing & Tooling

How to anchor stochastic agents in deterministic truth

#3: Test-Driven Verification Loop

Writing a failing reproducer test first yielded 3.2x faster completion than asking the agent to "fix the bug directly".

A failing test serves as an automated loss function for the agent.

#4: Tool Design & CLI Hygiene

Agents need high-signal tools: IDE AST lookups and bounded, non-interactive terminal executions with structured diffs.

Unbounded logs and interactive CLI prompts break agent autonomy.

"In agentic programming, TDD is no longer just a best practice — it is the primary steering mechanism."
[21:00 - 23:00]
Insight 3: TDD is the steering mechanism (3.2x faster with reproducer tests). Insight 4: High-signal IDE tools beat raw CLI dumps.

Insights 5 & 6: Humans & Tech Stacks

Team dynamics and compiler mechanics under agentic amplification

#5: Junior + Agent = Mid-Level Velocity*

Sophomores achieved task completion velocity comparable to mid-level engineers.

*The Asterisk: Requires senior mentors to set architectural contracts and review diffs. Without review, tech debt accumulates.

#6: Language & Compiler Feedback

Strongly typed languages (Kotlin, Rust, Go, TS) provide instant compiler feedback that guides agents with precision.

In large monorepos, specialized tool caches avoid minutes-long build delays.

[23:00 - 25:00]
Insight 5: Juniors achieve mid-level output with senior mentor guardrails. Insight 6: Strong types and compiler feedback guide agents reliably.
