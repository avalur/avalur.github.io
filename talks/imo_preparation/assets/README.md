# Ассеты

Ничего из этого не запрашивается из сети во время показа — только при подготовке.

## Текстуры Земли (обязательно)

```bash
./assets/fetch_assets.sh
```

Кладёт в `textures/earth/` пять файлов из примеров three.js (цвет, нормали,
specular, облака, ночные огни). Исходно это NASA Blue Marble, public domain.

## Крупные снимки для глубокого зума (желательно)

Глобальная текстура 2048×1024 — это ~20 км на пиксель: на высоте 150 км от неё
остаётся коричневое пятно. Поэтому в нужные места вклеиваются «патчи» — куски
снимков повыше разрешением, они появляются по мере снижения (см.
`EARTH_PATCHES` в `src/config.js`).

```bash
python3 assets/fetch_patches.py               # оба патча
python3 assets/fetch_patches.py novosibirsk   # только один
```

Скрипт берёт снимки из NASA GIBS (публичный WMS, без ключей, public domain):

- **Сибирь, 1400 км** — Blue Marble Next Generation, 500 м/пиксель, уже без облаков;
- **Новосибирск, 300 км** — MODIS Terra true color, 250 м/пиксель. Съёмка
  ежедневная, а над Сибирью почти всегда облака, поэтому скрипт перебирает
  летние даты за несколько лет и выбирает самую чистую по средней яркости
  (облака яркие и однородные). На 2026 год выигрывает 5 августа 2023-го.

Патчи необязательны: если файла нет, сцена просто его пропускает (в консоли
будет `optional patch not found, skipping`).

Отсюда же следует, докуда можно снижаться. 250 м/пиксель на снимке в 1536
пикселей — это ~195 м на пиксель текстуры. На бите Академгородка (высота 30 км)
кадр даёт ~35 м/пиксель, то есть снимок растянут в 5–6 раз и заметно мылит.
Ниже спускаться уже нет смысла, пока не появятся снимки получше.

### Если нужно ещё детальнее

250 м/пиксель — предел бесплатного «ежедневного» покрытия. Чтобы увидеть
кварталы Академгородка, нужны Sentinel-2 (10 м) или снимки с дрона:

1. [Copernicus Browser](https://browser.dataspace.copernicus.eu/) → руками
   выбрать безоблачную дату → экспорт JPEG по нужному bbox;
2. положить как `textures/earth/patch_akademgorodok.jpg`;
3. добавить запись в `EARTH_PATCHES`: центр, `spanKm`, высоты `fadeIn`/`fadeOut`
   и `gain` (снимки не освещаются сценой, яркость задаётся вручную).

Bbox считается так же, как геометрия патча: квадрат `spanKm × spanKm`,
`halfDeg = spanKm / 2 / 111.19`, по долготе делённый на `cos(lat)`. В
`fetch_patches.py` это функция `bbox()`.

## Модель здания (пока нет)

`models/fmsh.glb` — экспорт из Blender. Ориентация: длинная сторона по X, вход
смотрит в +Z, начало координат на уровне земли, 1 единица = 1 метр. Появится
файл — `campus.js` заменит им заглушку сам, править код не нужно.
